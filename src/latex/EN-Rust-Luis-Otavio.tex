\projentry{Clipsync (clipboard synchronization)}{Tokio, WebSockets, mDNS, Wayland/X11}{github.com/luis-ota/clipsync}

  \item Configured Cargo tests, Clippy, and CLI smoke checks in GitHub Actions, with platform packaging (.deb/.rpm/PKGBUILD/Flatpak) and an Android APK build.
\end{cvbullets}
